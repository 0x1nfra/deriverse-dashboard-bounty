# Screenshots Directory

This directory contains screenshots for the Deriverse Trading Dashboard README.

## Required Screenshots

Please capture the following screenshots at **1440x900** resolution (or similar 16:10 aspect ratio):

### 1. overview-tab.png
- **Tab:** Overview
- **Content:** Show the portfolio value chart with visible drawdown shading, asset allocation donut chart, and recent activity table
- **Key features to highlight:** Drawdown visualization, chart tooltips, allocation percentages

- **Tab:** Trading
- **Content:** Open positions table, recent trades table, and performance chart
- **Key features to highlight:** Position details, trade entries, performance metrics

### 3. analytics-tab.png
- **Tab:** Analytics

### 5. volume-tab.png
- **Tab:** Volume & Fees
- **Content:** Volume summary cards (24h, 7d, 30d, All), trading volume bar chart, fee breakdown donut chart, order type analysis
- **Key features to highlight:** Volume trends, fee composition, order type performance

### 6. journal-tab.png
- **Tab:** Journal
- **Content:** Trading journal table with annotated entries, "New Entry" button visible
- **Key features to highlight:** Journal entries, annotation display, trade details

### 7. history-tab.png
- **Tab:** History

### 8. mobile-view.png
- **Device:** Mobile (iPhone SE or similar 375px width)
- **Tab:** Any (Overview recommended)
- **Content:** Show responsive layout with hamburger menu, stacked stats cards, scrollable chart
- **Key features to highlight:** Mobile-optimized layout, touch-friendly interface

## Screenshot Tips

1. **Browser:** Use Chrome or Safari with dev tools closed
2. **Zoom:** Set browser zoom to 100%
3. **Clean UI:** Hide bookmarks bar, close unnecessary tabs
4. **Data:** Use fresh page load to ensure consistent mock data
5. **Lighting:** Screenshots will look best with the dark theme (already applied)
6. **Annotations:** Make sure at least one screenshot shows an annotated trade
